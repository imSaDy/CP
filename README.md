# Competitive Programming

My C++ codes from ICPC preparation (2025).

- **Graph:** Dijkstra, Bellman-Ford, Floyd-Warshall, negative cycle detection, directed cycle detection, SCC, 2-SAT, two-edge-connected components, DSU, Kruskal, Euler path, Hamiltonian path, Hopcroft-Karp, bipartite matching, min cut, De Bruijn sequence, k shortest routes
- **Tree:** LCA, centroid decomposition, virtual tree, sack (DSU on tree), treap, link-cut tree, path and subtree sum queries
- **GraphBeforeExam:** bridges, articulation points, centroid decomposition, HLD, LCA, Euler path, SCC and 2-SAT, dynamic bipartiteness, segment tree merging
- **Flow:** Dinic, min cut, bipartite matching
- **DataStructure:** Fenwick tree, sparse table (RMQ), segment trees, HLD, Mo's algorithm
- **SegmentTrees:** lazy propagation, k-th smallest, order statistics, range assignment, range GCD, 2-D range max, fractional cascading, string hashing with updates, convex hull trick
- **SQRT:** Mo's algorithm, Mo on trees, Mo with updates, range mode query, sqrt decomposition
- **DP:** LIS, LCS, bitset knapsack, digit DP, broken-profile tiling, sum over subsets, rerooting, matrix exponentiation, Aliens trick
- **Combinitorics:** FFT, NTT, Catalan numbers, Stirling numbers, Lucas's theorem, inclusion-exclusion, Möbius inversion, Burnside's lemma, Kirchhoff's theorem, Lagrange interpolation
- **Strings:** KMP, double hashing, trie, Aho-Corasick, suffix array and LCP, suffix automaton, palindromic tree, Manacher, Lyndon factorization
- **Geometry:** primitives, convex hull, polygons
- **Math:** modular arithmetic, Josephus problem
- **Miscellaneous:** next greater/smaller element, sliding window
